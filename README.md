## Descripción del proyecto

Este proyecto utiliza un algoritmo genético programado en Python para encontrar una ruta de recorrido entre ocho ciudades, buscando reducir la distancia total.

El algoritmo trabaja con una población de soluciones y aplica selección, cruzamiento y mutación para generar nuevas rutas y buscar una solución de menor distancia.

## Tecnologías utilizadas

* Biblioteca DEAP.
* Matplotlib.

## Cómo ejecutar el programa

1. Instalar Python.

2. Instalar las bibliotecas necesarias con el siguiente comando:

   `python -m pip install deap matplotlib`

3. Ejecutar el programa:

   `python actividad6.py`

## Objetivo

Aplicar los conceptos de algoritmos genéticos para resolver un problema de optimización de rutas y observar cómo evoluciona la calidad de las soluciones durante las generaciones.

**Nota:** Las ciudades y sus coordenadas se utilizan como un ejemplo simulado para fines académicos.
